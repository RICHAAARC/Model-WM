# 当前 C 的一次末端求解器公平判别

**2026-11-19，设计定稿 v1。用途为大效应筛查。** 唯一主张是生成末端的第二次响应逆解在相当的实际成图质量、身份容量、误指认和预算下，能比普通优化更可靠地写入真实混合后仍可检出的用户证据。方向固定为 C 优于普通臂 O。本次已锁定规则并完成设计计算。新作品清单、随机化表、人员与运行版本尚未封存；本文件不构成实验已经注册到外部平台或获准启动 GPU 的回执。

## 1．唯一处理差异

沿用旧 latent_control 的 SD1.5 revision、末端 VAE、512×512、25 步、CFG 7.5、调度器、float32、P、原 64 个正交身份、16 名注册者、分阶段外来池、基准幅度 a 与读出归一化。模型与码见[历史 manifest](../../colab_release/latent_control/manifest.json)，旧作品清单只用于排重。只允许写入目标乘全局增益 g，读者始终用原 a。每作品每臂交付相同两名注册、两名外来用户的四副本。

一次生成 z，同一次原始 64 行 Jacobian 与原正则逆产生 zc，两臂收到同一个 zc 和中心读出 rc；普通臂不接收中心处新 Jacobian、逆矩阵或 C 的端点。基础任务是从 zc 找到 u，使未量化 RGB 的平方残差 ||P D(zc+u)/a − g c_i||² 足够小。最终输出均经原解码、clamp、uint8 量化流程。

- C 在 zc 取 64 行新响应，按现有 trace 正则逆一步给出每个 u。只把原式中的目标 a c_i 替换成 g a c_i。原秩/非有限失败照记。
- O 从 u=0 分用户以 L-BFGS 最小化同一残差，沿用 lr=1、strong Wolfe、history=10、梯度/变化容差 1e−7/1e−9。每户至多 16 个实际 closure（线搜索也计），四户共 64 次末端 VJP。到限返回实际评估过的最低有限目标点，平局取先到点，复用该点缓存 RGB。正常收敛可以提前结束；非有限、没有有效点或模型异常保留失败。两臂均不按 clean MSE/SSIM、攻击分数或最终人评挑选中间端点。不采用旧 B 的质量筛点，也不采用此前 8+4×30 的另一种公共中心。C 的局部阻尼和 O 的线搜索各属其求解器。
- 两臂都看得到本次要写的用户码。四份写入只调用单户目标，端点不得依赖配对标签。检测仅用收到的 RGB、key、注册表和可信 work_id，严格返回全部过阈值身份。真成员只用于 CAL 计算无辜分数及事后评判。

## 2．独立数据及顺序

新内容族 136 个，每族一件，DEV 8、CAL 64、TEST 64，TRAIN 0。面向事前声明的同作品图像分布，不以旧失败类型加权；先登记候选来源、内容族定义、提示和历史用途，对照 QIM、AquaLoRA、WAM、历次 latent-control 的清单及审图记录。近重复、改写旧提示或新 seed 复用同一作品不得算新内容。来源缺口或冻结后发现串组，整次停止。基础模型训练史保持 UNVERIFIED。

在看任何生成结果前，一次封存采样框、136 个作品和分组、生成 seed、身份配对、臂顺序、盲评随机编码、使用版本及本文件。登记分配用的随机种子后一次无放回划分，内容族跨组不交叠。每件从固定 16 名注册者中均匀无放回取两名，从该阶段原外来池取两名；配对在作品之间可重复。CAL/TEST 程序只解锁本阶段。同作品跨臂共享底图/seed/身份，不宣称每作品覆盖 120 个注册身份对。旧 TEST 和旧 CAL 均不得纳入。若缺乏可核名单、盲评人力或资源上限，停止在预注册。

## 3．只在 DEV 选一次强度

两臂每件都使用 g∈{0.5, 1, 2}，共 3 档，分别是旧幅度的半倍、原值和两倍，覆盖“单纯加力”的直接解释。严禁插值、补点、按作品变强度或扩大网格。每件的公共中心只做一次；C 可复用其中心响应，O 可复用公共信息，每个目标从同一零偏移出发。DEV 每件每档计算和保存与正式阶段相同的 22 行，先封存匿名视觉表，再算选强度所需的分数。

一臂一档的 DEV 追踪排名量是 8 个作品余量的中位数。每作品取六个真实注册混合中“最高真成员分数”的最小值，再减去本作品整套 22 行中最高无辜注册分数。该量只用于 DEV 排序，不是 CAL 阈值。两臂分别按此量降序排名，同值先取较小 g。两臂使用各自最合适的 g，无需同一标称幅度。

枚举 9 个跨臂强度组合。可比的组合要求两臂在 8 件上都完整、两个视觉维度逐件均≥1，且两个维度各自的跨臂平均分绝对差均≤0.25（量表见下节）。在可比组合中按以下键最小者唯一选出：较差一臂的臂内名次、两臂名次之和、两臂 g 之和、较大的 g、盲码 A 的 g（盲码在看图前固定）。这条对称优先规则不使用 C−O 的差值。若无可比组合则 STOP_DEV。两臂各一个选中强度、完整九格表及实际 DEV 用量封存后进入 CAL。仅能排除该预定强度范围内的简单替代；边界最优须披露。

## 4．主体一致性与自然度

盲评单位为一作品一臂一档的整组图。DEV 48 组、TEST 128 组，每组含四个原生 PNG、注册混合的三权重×两编码六图，均可按原 512×512 检视。初始界面给 prompt 与无水印底图作为主体/构图参照，允许不同局部纹理、雕塑裂纹和水面细节。不计算与参照的逐像素相似门。隐藏臂、强度、身份、追踪结果、执行顺序；两名独立人评各看所有匿名组，不并排标出竞争者。此验收只涵盖交付原生图和目标注册混合，不外推到其余媒体。

每组按最差可见问题，对以下两个维度分别给 0/1/2，并记录触发图和理由：

|维度|2|1|0|
|---|---|---|---|
|主体一致性|主体、布局、关键部件和主要内容保持；可有局部细节变化|局部边缘/次要部件有可见偏移，仍明确是同一作品|主体、数量、主要布局或关键结构改变，或明显双主体|
|自然度与可用性|正常观看无明显伪影，自然可用|有轻微可见瑕疵，仍基本可交付|明显重影、结构异常或覆盖性噪声，影响使用|

两人一致取该值；有分歧或无法判断时第三人独立评该维度，取三个数字的中位数。若有缺票但已有两张相同数字取该数，其余记 UNRESOLVED。TEST 视觉表在查看 TEST 分数或方法标签前封存。每臂须至少 60/64 件两维均≥1；另要求 TEST 两维各自的跨臂均分绝对差≤0.25，且两臂可交付件数差的绝对值≤2。阈值是本次可比性的前瞻性操作定义，不是视觉等效的总体置信区间。所有有视觉 0 的作品保留，按本臂主结果失败。未决或漏评阻止整体 PASS。PSNR/SSIM 仅作描述。

## 5．CAL 与作品级判决

沿用真实 uint8 RGB 混合 w=0.25/0.50/0.75（最近整数），PNG 或 JPEG85、subsampling=2。每臂每作品 22 行为无水印、四原生、三注册混合、三外来混合，各两编码。取每行所有非真实成员注册分数的最大值，再跨行、跨 64 件 CAL 取最大值得该臂 τ。分臂保存全部 maxima、阈值与输入清单，封存且回读后才允许生成第一件 TEST。任一 CAL 缺行或无效即止。严格 >τ 才返回，不在 TEST 重校准。

TEST 一件成功须同时满足媒体与评分完整、两维视觉均≥1、六个真实注册混合各至少返回一个真成员。两臂同件配对；按固定 64 件列出两者均成、仅 C 成（W）、仅 O 成（L）、均败。个别物理失败/中断计入原分母和费用，不可补做；凡不能完整核查风险、配对或视觉门，一律不能宣布通过。CAL/TEST 读出与视觉裁决责任隔离。错误返回与是否同时抓到真成员独立统计。

**全部成立才通过**：

1. 两臂包完整、资源与视觉可比门通过，且 C 的作品级成功数≥48/64。
2. Δ̂=(W−L)/64≥8/64（12.5 个百分点），且给定 W+L 的精确单侧配对符号检验 p=P[Bin(W+L,½)≥W]≤0.05；全平 p=1。沿用最早鲁棒性方案的最低可用和效应尺度，撤销旧像素门、速度门。例：13 胜 5 负达配对门，14 胜 6 负同为净 8 件却不达显著性。报告四格、净差及区间；区间可用 W/64 和 L/64 各 97.5% 双侧 Clopper–Pearson 的上下界交叉相减，Bonferroni 至少 95% 覆盖。12.5 点是观察到的最小有用差，检验针对总体零增益；不声称总体至少提高 12.5 点。
3. 对一件作品，任一臂、任一行向任一无辜注册者过阈值，记一次联合误归属（包括无水印、同码外来原生及混合、注册原生与混合中的无辜者）。要求 0/64，报告各臂和各类事件并保留哪件出错。独立同分布作品条件下 0/64 对应单侧 95% 精确上界 4.573%；任一事件阻止 PASS。CAL 最大值在交换性成立时才有边际秩解释，外来池分割及语义分布变化限制外推。不能声称部署 FWER<1%。

不做中途效应查看或提前报胜。除资源、来源、完整性或封存阻塞外，按冻结分母完成后统一裁决，不因早期误指认删记录。报告失败类别：质量不匹配、拒识失败、优势未达门、资源/数据不完整。若 O 追平或区间宽，均结束本次候选扩展；后者只说明未分辨，不能判等效。若 O 在本样本已成功≥57/64，纵使 C 64/64 也不可能净增 8 件。

## 6．规模与功效

用[精确枚举脚本](design_check.py)检验上述统计门。假设独立作品且给定已冻结的方法及阈值，令 d=P(仅 C 成)−P(仅 O 成)，q=P(两臂不同)，假设 C 作品级成功率 0.85。则胜、负概率各为 (q±d)/2，其余两格由 C 成功率补齐。遍历不一致数、胜数、共同成功数，联合计算 C≥48、净增≥8 与 p≤0.05。q 取 0.25/0.35 作敏感性情景；未使用旧 B/C 的不公平差距估算新臂概率。

|真实净差|q=25% 时通过追踪门|q=35% 时通过追踪门|
|---:|---:|---:|
|5 个百分点|12.6%|12.1%|
|10 个百分点|36.9%|31.3%|
|12.5 个百分点|53.3%|44.6%|
|15 个百分点|69.6%|59.0%|
|20 个百分点|92.0%|83.8%|
|25 个百分点|98.4%|96.0%|

按 0.1 个百分点网格，达到 80% 追踪功效约需 16.9 或 19.1 点净增。上述数值已含作品级质量合格对成功率的影响，但未包含整体视觉可比性、资源完整性和联合零误归属门。若给定阈值后联合错误率为 r，风险门通过概率单独为 (1−r)^64：r=0.5%、1%、1/64 时为 72.6%、52.6%、36.5%。全门通过概率不超过其中任一门的通过概率，不假设独立相乘。单独风险门要有 80% 通过概率，r 须不高于约 0.35%。旧 1/64 只是观察，不能用于预测新方法的真实 r。

裁定：这是一次识别约 20 点大优势的筛查；未证明多数真实情景均有 80% 综合把握。如果研究目的要求可靠分辨 5–10 点或验证生产级低误归属，当前方案在准备阶段即止，不以增加样本、降低门槛或追加一次来补救。

## 7．固定预算与实施边界

以已完成旧 136 件两臂的实测准备 360.89 秒、模型阶段 8,038.17 秒为量级依据。DEV 三档计费，合计 136 个独立起点、152 个作品×强度。保守按旧均价折算 152/136×8,038.17≈8,984 秒模型，未实测新对照，不能担保跑完。

|累计硬上限|本次设计值|
|---|---|
|扩散生成与去噪|136 次，3,400 步；同件跨强度、两臂共享|
|最终原生副本与最终读出|每臂 608 份，共 1,216 份；每臂 3,344 行，共 6,688 行（含 DEV；不同于优化调用）|
|VJP|共用宿主中心 136×64=8,704；C 中心响应 136×64=8,704；O 最多 152×4×16=9,728。物理总上限 27,136；独立部署上限 C 17,408、O 18,432，二者各含公共中心，物理总账只收一次|
|VAE 解码|初始/中心各 136 次，C 最终 608 次，O closure 最多 9,728 次并缓存最优已评 RGB，合计≤10,608；无免费最终解码|
|准备与模型|准备累计≤900 秒，模型加载、DEV/CAL/TEST、模型在线期间 IO/封存累计≤10,800 秒（含 60 秒结算预留），总计算占用≤11,700 秒，阶段不互借；CPU≤14,400 核秒，RAM≤32 GiB，单卡 VRAM≤24 GiB，结果≤4 GiB。下载实报，只在临时 /content 缓存权重|
|人工|176 个匿名组，两名主评各 176 组，第三人最多复核 176 组；三人总计≤20 人时，含裁决与录入。设此上限用于控制成本，不得为赶时限跳评|

执行前登记两臂共用的设备型号与软件环境。物理调用先预留，失败计费，全部历史账留存。盲评等待时结束付费运行时或继续扣实际占用，禁止让 GPU 空等再从账上扣掉；正常 DEV→CAL 跨会话若需重新准备/加载均计入相应累计阶段。仅从完整封存阶段继续；任何已启动作品不得再算一次。DEV 结束按选中档位的实测逐件两臂总物理耗时取最大值（共享步骤计一次），以 128×该值加剩余加载/封存预留和已耗检查预算，同时按已用字节/剩余件数检查磁盘；无可靠剩余估算或预计/实耗触线即止。全账覆盖盲评归档与技术失败，保留各阶段收据。此次只交付设计和精确计算，没有新增 GPU 预算授权、模型输出、阈值或数据分配。
