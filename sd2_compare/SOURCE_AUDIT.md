# Source and interface resolution — 2026-11-25

The prior audit's official-source 401 remains a fact. New evidence resolves the usable distribution route: [Hugging Face's own Optimum Habana documentation](https://huggingface.co/docs/optimum-habana/tutorials/stable_diffusion) identifies the withdrawn SD2 family and explicitly recommends the sd2-community mirrors, including the 512-base model. The experiment therefore uses that disclosed community distribution, not an unverified claim of current Stability maintenance. Fixed revision 4e63672c03103b6c636b8fb4119ba982469b2955 is preserved. Historical bitwise equality to inaccessible official assets has not been established and is not asserted.

Pinned live metadata parses as four latent channels, sample size 64, 1024-dimensional cross attention, 23-layer converted OpenCLIP text encoder, and epsilon prediction. The 23-layer encoder is the converted penultimate-layer representation; no extra clip_skip is applied. [Diffusers v0.31.0 conversion source](https://github.com/huggingface/diffusers/blob/v0.31.0/src/diffusers/pipelines/stable_diffusion/convert_from_ckpt.py) documents both conversion and the SD scaling convention. The archived original v2-inference YAML explicitly specifies scale_factor=0.18215 and the KL-f8 first stage. Its archive is secondary provenance, cross-checked with the maintained conversion implementation; missing scaling_factor in old Diffusers JSON is not taken as a newly measured property.

The pinned LaWa author's source also includes `stable-diffusion/configs/stable-diffusion/v2-inference-v.yaml` with scale_factor=0.18215 and the KL-f8 first stage. Its local archival copy is `source_evidence/lawa_v2_inference.yaml`. This independently corroborates the scale convention; it is not used to replace the base-512 model's explicit epsilon scheduler with a v-prediction scheduler.

SD1.4 and SD2 VAE metadata share the KL-f8 shape family; this is not proof of identical learned coordinates or weights. We deliberately keep SD1.4's clean decoder and the same LaWa writer/reader. This controls decoding while varying the denoiser/text encoder. No SD2 VAE weights will be downloaded by the entry. The first two scheduled DEV works determine actual image suitability, so semantic compatibility is not declared proven by CPU parsing. If those images are unusable, stop the route; do not switch VAE or model to rescue it.

All downloaded evidence is small metadata, tokenizer data or source code. `source_evidence/sources.json` contains exact URLs and archival identities. No pretrained tensor was downloaded or loaded in this engineering stage. CPU synthetic tests exercise the actual pinned component loading classes and pipeline, but cannot establish GPU performance, real-weight integrity or scientific benefit.
